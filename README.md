# Driver-Not-Found

ชื่อทีม : Driver Not Found
ชื่อโครงงาน : ระบบคลังโปรแกรมและไดรเวอร์ออนไลน์สำหรับการเรียนการสอน
ปัญหาที่จะแก้ : ใครเจอ: นักศึกษาและครูในวิทยาลัย
เจออะไร: ทุกครั้งที่ลงเครื่องใหม่หรือเริ่มเรียนวิชาใหม่
ต้องตามหาโปรแกรมที่ใช้เรียนและไดรเวอร์ (เช่น ไดรเวอร์ USB-Serial
ของบอร์ด ESP32, Raspberry Pi Imager, VirtualBox, XAMPP,
ไดรเวอร์ปริ้นเตอร์) จากหลายเว็บไซต์เอง เสียเวลา
ได้เวอร์ชันไม่ตรงกับที่ครูสอน
และบางครั้งได้ไฟล์จากเว็บที่ไม่น่าเชื่อถือ
หรือก๊อปผ่านแฟลชไดรฟ์ที่เสี่ยงติดไวรัส
บ่อยแค่ไหน: เกิดขึ้นทุกต้นภาคเรียนและทุกครั้งที่เริ่มงานใหม่
(ยืนยันความถี่จากการสัมภาษณ์)

ผู้ใช้ระบบ : 1. ผู้ดูแลคลัง (ครูหรือนักศึกษาช่วยงาน) – เพิ่ม/แก้ไขโปรแกรม
จัดหมวดหมู่ เขียนวิธีติดตั้ง
          2. ผู้ใช้ทั่วไป (นักศึกษาและครู) – ค้นหา อ่านวิธีติดตั้ง ดาวน์โหลด
และตรวจสอบไฟล์ด้วย checksum
